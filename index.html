Programación Orientada a Objetos (POO) en el Videojuego

Conceptos Fundamentales
• Clase:
Plantilla o molde genérico para crear objetos.
• Atributos:
Variables internas que definen el estado o propiedades.
• Métodos:
Funciones internas que definen el comportamiento o acciones.
• Instancia (Objeto):
Ejemplar concreto y real creado en memoria a partir de la clase.
Ejemplo Práctico en Python
class Jugador:
    def __init__(self, x, y):
        self.pos = [x, y]  ← Atributo
        self.vida = 100    ← Atributo

    def mover(self, dx):   ← Método
        self.pos[0] += dx

# Instanciación en memoria
j1 = Jugador(2, 6)         ← Instancia
